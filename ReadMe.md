# Synthé — The AR/VR Creator Platform

🔗 **Live:** [synthe-nu.vercel.app](https://synthe-nu.vercel.app)

## About

Synthé is an AR/VR creator platform — a tool/utility app that lets creators **build, share, and monetize** AR/VR experiences. It brings together a 3D model marketplace, live workshops, mentor booking, and AI-powered XR learning paths in one place.

## ✨ Features

- 🛍️ Browse and use a library of 3D models
- 💰 Build, share & monetize your own AR/VR experiences
- 🎓 Join live workshops and book mentors
- 🤖 Generate AI-powered XR learning paths
