# SYNTHÉ — Project Overview

## What is SYNTHÉ?

SYNTHÉ is an AI-powered AR/VR creator platform built
with Next.js 16, Firebase, and Google Gemini AI.

It is designed for XR developers, 3D artists, students,
and professionals who want to build, share, learn, and
monetize immersive experiences.

---

## Core Modules

### 1. 3D Verse (Marketplace)
- Browse, upload, buy, and sell 3D models (GLB, GLTF, OBJ, FBX)
- Live WebGL preview with hover-to-spin interaction
- AR viewer — place any 3D model in your room via WebXR
- Commission custom 3D models through post requests
- Cloudflare R2 storage for binary asset hosting

### 2. XR Zone
- AR/VR project showcase from verified developers
- Upload and share AR and VR applications
- WebXR-native — no app install required

### 3. AutoCAD Hub
- Browse and share DWG/DXF engineering blueprints
- Professional preview and file management

### 4. Learn Hub (AI-Powered)
- Free live AR/VR workshops by verified mentors
- AI-personalised XR learning roadmaps (Gemini 2.0 Flash)
- 48 curated XR tools, rated and filtered
- XR challenges with community badges
- Student showcase gallery
- Book 1-on-1 mentors (Razorpay payments)

### 5. Finalize (Execution Pipeline)
- Paste any AI output → get structured execution plan
- 4-layer pipeline: Prompt Controller → Gemini → Finalizer → Output
- Priority scoring (P0/P1/P2), dependency ordering
- Adaptive Intelligence — session-based learning from user behaviour

### 6. Freelance
- Post XR project requests and receive developer bids
- Browse open requests from clients
- Hire verified XR specialists

### 7. Connect
- Real-time chat between creators, students, and mentors
- AI-powered smart replies and message drafting
- Community networking and collaborations

### 8. Certification
- Developer verification and badge system
- Professional profile validation

### 9. PIET Collaborators
- Academic collaboration hub
- Institution-linked developer profiles

## AI Execution Pipeline

The platform implements a patent-oriented 4-layer AI
execution system:

```
User Input
  → Layer 1: Prompt Controller (sanitise, structure, inject adaptive context)
  → Layer 2: Gemini Service (API call, JSON validation, error recovery)
  → Layer 3: Utility Finalizer (priority scoring, dependency sort, checklist)
  → Layer 4: Adaptive Engine (session memory, skill detection, pattern learning)
  → Structured Output → UI
```

Key differentiators:
- Gemini is NEVER called with raw user input
- Output is priority-ranked (P0/P1/P2) and dependency-ordered
- Session-based adaptation personalises future outputs
- Deterministic post-processing via TypeScript (no extra AI call)

/scripts                — Build/deploy scripts

## Environment Variables

Required in `.env.local`:
- NEXT_PUBLIC_GEMINI_API_KEY — Google AI Studio API key
- NEXT_PUBLIC_FIREBASE_* — Firebase project credentials
- NEXT_PUBLIC_SUPABASE_URL/ANON_KEY — Supabase
- CLOUDFLARE_R2_* — R2 storage credentials
- RAZORPAY_KEY_ID/KEY_SECRET — Payment gateway
- NEXT_PUBLIC_CLOUDINARY_* — Image CDN
